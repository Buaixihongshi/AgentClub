# CLI 故障诊断与跨任务产物交接契约

来源：[2026-10-16 事故记录](../incidents/2026-10-16-cli-timeout-and-handoff.md)。

## 失败诊断

- 登录预检失败不代表最终认证失败。聚合日志必须尊重成功/失败发生顺序；成功后的新失败仍应提示。
- CLI 内部超时和宿主硬超时分开记录。兼容 supported CLI 在 stdout 或 stderr 输出的已知格式，不只匹配旧版本单一字符串。
- 无 MCP `publish_message` 时不把 stdout 当作发言；进程被终止不代表之前的文件修改被撤销。
- 默认诊断保存本机受限目录，限制每条大小及保留条数，脱敏常见凭据，不默认复制 MCP config/env，不返回绝对日志路径或内容到聊天。
- 诊断 IO 失败不能覆盖原本的调用结果。测试覆盖正常退出、宿主超时、provider 内部超时及写入失败。

## 超时配置

- `cli_timeout` 是初始及续期后的执行窗口，当前本机配置为 600 秒。宿主每 300 秒检查一次新工具结果；有结果时将截止更新为该检查点之后一个执行窗口，没有新结果则保留原截止。相同返回只消费一次，后续真实的新调用仍可续时，不另加累计硬上限。
- 普通任务和 A2A 使用相同续时规则。原生文件/命令/测试实际返回（包括失败和空结果）可以续时；Claude 参数生成结束、工具启动、普通正文、生成元数据、计划记录和状态心跳不能续时。Hub 读取/写入结果按任务与回合关联，其他回合的结果不计入。
- Antigravity 内部固定 print timeout 关闭，由宿主控制截止。常驻工作进程及隔离讨论在续时时同步延长当前执行凭证，不改变身份、权限或任务终态。已撤销的凭证不能续期。
- 每次续时保存 `turn.deadline_extended`，包含新工具结果数量、原截止及新截止；诊断记录 `deadline_extensions`、`progress_check_interval_seconds`、`effective_timeout_seconds`。历史超时状态不改写。

- `hub_settings.json` 用户设置优先于环境和默认值。修改默认值不能迁移用户的显式设置。
- 变更生效值后验证设置 API、`snapshot_settings` 和创建的 provider adapter；每个新任务读取新快照。
- 无 reload 的服务需要重启才能加载 Python 实现变更。先查活动任务，保留数据库和配置备份，再重启、验证健康与历史会话。

## 产物交接

- `write_artifact` 接受 `relative_path`，以及二选一的 `content` / `source_path`。已有文件优先使用 `source_path`，无需模型重新输出全文。相对来源路径基于宿主签发的工作区根目录；绝对路径也须位于工作区，历史产物须来自当前任务或同一非空会话。
- 导入按原始字节复制，限普通文件、10 MiB；越界路径、符号链接越界、目录及超大文件返回工具错误。文件原子保存后才写入 `artifact` 事件。
- 任务快照 / SSE 与会话详情提供 `artifact_events`，由已登记事件派生文件卡片，不写入正式消息历史。同一任务同一路径只展示最新登记；超时、后续请求及刷新不会删除卡片。未登记的临时文件不生成卡片。
- 文件卡片标明“文件已保存”，不表示任务完成或内容已验证；可预览、下载，HTML 在不具备同源权限的 sandbox iframe 中展示。`GET /api/missions/{id}/artifacts/file?path=...` 按原始字节提供附件下载，沿用任务产物目录边界。

- 产物标识为 `(source_mission_id, relative_path)`，相同文件名不能跨任务去重。
- prompt 产物索引包含同一会话的历史任务，明确提供来源 ID；读取通过 MCP `read_artifact` 传递该 ID。
- 未指定来源时只读当前任务。显式跨任务时，两任务必须属于同一非空 conversation；不允许无 conversation 的任务互读。
- 在来源任务的产物目录中 resolve 路径并校验包含关系；拒绝 `..` 和符号链接越界。
- 回归至少覆盖历史产物发现、stdio MCP 来源参数传递、同名不同来源、跨会话拒绝、空会话拒绝、路径及符号链接越界。
