# Antigravity 常驻进程与中断恢复

本功能默认关闭。启用环境变量
`YIREN_ANTIGRAVITY_PERSISTENT=true` 后，真实任务使用 `stream-json`
双向管道；演示模式及首次 Provider 验证仍走原有路径。

## 进程与上下文

- 缓存键包含数据库、产物根目录、会话、角色、Provider、启动参数、工作目录和额外环境。
- 由于当前 agy 使用全局 MCP 配置，一个后端进程只保留一个工作进程。换会话、角色或启动配置即回收，不能共享模型历史。
- 每次收到 `result` 才领取下一轮。默认最多复用 12 轮，空闲 15 秒后回收并恢复原 MCP 配置；关闭服务也会回收。
- 配置文件沿用跨进程独占锁和备份哨兵。等待锁计入启动预算；启动恢复不会等待仍在运行的合法锁持有者。
- 当前不在用户打开页面时主动预热，也不在服务启动时发送模型请求。

## 每轮凭证与幂等

`execution_workers` 与 `execution_grants` 保存宿主状态。每轮生成随机
`context_token`，数据库只保存 SHA-256；凭证绑定工作进程、递增代次、
任务、角色、回合、Provider 和截止时间。所有 MCP 工具必须显式携带
当前凭证，不能按“当前连接”猜测迟到调用属于哪一轮。

稳定的 `session_server` 从凭证解析身份，模型不能通过参数选择任务。
鉴权、回合检查、数据库工具写入及操作回执在同一个 `BEGIN IMMEDIATE`
事务中执行；结束时再检查凭证期限。旧凭证、跨进程凭证及终态任务均拒绝。

有副作用的 MCP 工具还必须携带 `operation_id`。同一逻辑操作以相同参数
重试时返回既有结果，参数冲突则报错。`publish_message` 的逻辑编号统一
为 `final`，每轮只有一条正式回复；不能换编号绕过发布去重。

这保证已确认的数据库操作不重复；文件系统和远端服务不能被 SQLite
事务回滚，不能据此承诺所有原生操作恰好执行一次。

## 进程丢失

1. 宿主检测退出、管道 EOF、总预算或空闲预算超时。
2. 先撤销执行凭证，再终止 CLI 进程组并恢复全局 MCP 配置。
3. 核对正式消息及 MCP 回执：回复已保存则保留回复并记录警告；未发布则阻塞。
4. 不自动重放已交给 CLI 的请求。没有收到工具事件，也不能证明原生副作用未发生。
5. 后续请求会重建进程，使用宿主构建的正式历史，并获得已保存的中断动作摘要，先核对工作区和消息再继续。

工作进程 ID、原生会话 ID、工作目录和最后的安全动作摘要持久化。
不把原生内部推理或命令输出加入恢复提示。恢复成功后不再重复添加旧警告。
原生会话不完整时不尝试强行恢复其内部状态。
中断诊断沿用有界私有 JSON 日志，记录进程/会话编号及脱敏 stderr；
新增执行凭证脱敏，不把 stdout 中的工具参数写入诊断副本。

独立监护进程持有一条只有宿主保留写端的管道。即使宿主被 SIGKILL，
管道 EOF 也会触发终止 CLI 进程组，避免普通子进程孤留。主动脱离该进程组
的外部任务仍需按实际资源核对，本机制不是操作系统级全局任务沙箱。

服务重启时撤销旧凭证；遗留任务标记中断，保留历史并要求核对，不自动重跑。
沿用项目的单后端进程模型，不支持多个独立服务共享同一个数据库做恢复。

## 协议与用量

正式消息仍必须经 `publish_message` 发布，不从 stdout 合成消息。
原生工具事件记录为 `provider.activity`，流式文本可刷新活动时间。
`result.usage` 在常驻会话中是累计值；写入每轮用量前按同一工作进程的前值作差。

## 验证与回退

```sh
python -m pytest backend/tests/test_execution_recovery.py backend/tests/test_antigravity_config.py -q
python -m pytest backend/tests -q
```

覆盖真实子进程/stdio MCP 的跨轮复用、旧凭证拒绝、角色隔离、并发发布去重、
发布事务回滚、超时、发布前后崩溃、空闲回收、HTTP 后续任务接入及宿主 SIGKILL。

具体版本的测试结果及 STAR 复盘见 [升级记录](../upgrades/2026-10-18-antigravity-session-recovery.md)。

隔离真实 CLI 验收：同一原生进程完成两项任务，每轮新凭证均成功调用
`log_thought → publish_message`，分别约 22.54 秒、10.86 秒。该结果包含
两次 MCP 调用和模型耗时，不等同于纯启动基准，也不保证固定提速比例。

回退时关闭 `YIREN_ANTIGRAVITY_PERSISTENT` 并正常重启服务即可恢复每轮启动方式。
历史任务、消息和执行账本保留；不执行生产部署或 Owner release。
