# 对话优先与原设计语言统一

按用户图 1 复用原有纸白、鼠尾草绿、深灰、粗描边、轻硬阴影和点阵背景，所有会话使用同一个应用壳。保留对话／任务视图，不复用旧长表单作为任务首页。

默认发送消息与 @ 成员澄清需求，不要求选择交付模式。角色可通过 propose_work 提交持久任务提议，提议包含来源轮次、责任人、目标、范围、验收条件及交付终点；仅人类可接受或拒绝，接受时引用准确提议 ID 和 revision，并保存授权来源。不从普通聊天猜测开发或发布授权。任务页无建任务表单；通过回到对话继续调整需求。

技术范围：复用 React、Lucide、react-markdown、现有原生对话框与共享任务存储；不增加依赖、状态管理库或第二套组件框架。提议保存在已有 work_boards 文档内，旧记录缺省为空，不进行数据库迁移。既有审核与上线审批继续绑定约定和候选。

验收：提议未接受时没有可调度任务；旧 revision、重复操作、过期角色执行、归档会话均正确处理；对话输入 @ 补全及草稿保持；图 1 应用壳在新建和已有会话一致；桌面与 390px 视口无溢出。真实模型验证沿用日常路由与模型；离线替身不得称为真实团队验收。开发候选更新到 5180，未合入主线，不称 alpha 验收。

参考：Clowder README.zh-CN.md、ChatInput.tsx（聊天 @ 输入）、TaskBoardPanel.tsx（持续任务状态分组，细步骤留在对话）、TaskComposer.tsx（也支持可选手动建任务）。参考交互职责，不引入其依赖或品牌资产。
