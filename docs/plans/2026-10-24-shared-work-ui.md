# 共享任务双视图

用户选择第二版设计：会话内提供对话／任务标签，减少任务记录对聊天的挤占。

## 范围与依赖

依赖尚未合入主线的 adaptive_v1 开发候选；基线为 9305049。只调整前端呈现、交互及可选字段类型，不改变后端调度、审核或发布授权。

- 对话页只保留状态和待办入口，后台持续读取任务。切换标签保留草稿和滚动节点。
- 任务页展示交付负责人、当前状态、待决定事项、最近关键记录、交付物；较早记录可展开，完整原始事件仍可读取。
- 人工决定显示实际选择结果。审核摘要必须匹配任务的需求约定与候选快照；历史结果不套用当前版本。
- 审批在独立对话框中展示版本、目标环境和证据。修订冲突重新读取状态，不能重用旧决定或丢失反馈。
- 长路径收进文件来源。HTML、Markdown、图片按需预览，默认不挂载 iframe。
- 文案与样式采用轻量、清晰的层级，保留运行身份入口；旧协议功能继续可用。

## 验收

1. 聊天区不再出现占据半屏的共享任务板；待办在聊天页仍可发现。
2. 对话／任务可用鼠标和键盘切换；草稿不因切换丢失。
3. 查看任务流可识别人物、动作、时间，展开后能核对来源记录和对应版本。
4. 文件预览打开后使用已保存的准确快照；关闭返回原视图，旧版审批没有可批准动作。
5. 无 UI 的任务不展示空的设计阶段，多个根任务可切换。
6. 桌面与 390px 宽度无页面横向溢出，聊天输入和任务主动作可达。
7. 真实浏览器只读核对现有开发任务，不代用户批准上线、取消任务或触发 CLI。

## 验证与恢复

运行前端全量测试、类型／构建、diff 与隐私检查，使用 ego-browser 对照选定效果图检查真实页面。浏览器验证先在隔离开发工作区执行，通过后停止 5180，将本次前端差异更新过去，再按原状态目录重启并核对任务数据和运行身份。

不修改日常和 alpha。保留 5180 原前端文件备份，回退时在停止实例后恢复本次差异；不覆盖既有任务、聊天和其他未提交改动。
