- 从“多个 CLI 的角色聊天室”补全为“对话澄清、提议确认、持久工作、文件交付”的产品流程。
- 将旧的多人讨论模式切换说明改为当前 `/discuss` 技能入口，保留六阶段协议及 V1 兼容边界。
- 补齐自定义 API 协议、角色模型覆盖、主用/备用连接；明确文本 API 与 CLI 执行能力差异。
- 补齐对话/任务双视图、独立任务目录、受管预览、内容快照、版本化审核和上线核对。
- 补齐长期记忆、滚动检查点、遗忘/恢复、索引重建及模型交接。
- 补齐文件直接导入、超时后产物保留，以及观测、评测和仓库维护基础。
- 更新环境与发布说明；区分开发候选、主线 alpha、日常发布，删除过时的独立 Owner approval 预期。
- 明确 Linux 与 macOS 能力差别、当前串行执行、单用户范围，以及历史验证数字的时间边界。

## 可直接使用的更新动态

Unity 项目介绍更新到第二版：除了统一多种 AI CLI，现在还整理了对话式任务提议、持久自主工作、独立任务目录与预览、长期记忆与模型交接、文件交付和回合观测。同步公开三类工程复盘：真实 CLI 隔离启动、大文件交付超时、结果提交与续租竞态。新增能力的适用平台、验证范围和现有限制均在文档中列明。
