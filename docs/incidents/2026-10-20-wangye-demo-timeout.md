## 为什么界面只显示超时

适配器当前主要等待 CLI 进程退出或达到宿主截止。CLI 的 503 / result ERROR 留在 stdout 诊断里；硬超时分支优先生成超时摘要，stderr 仅有 `error: interrupted`，因此 503 没进入最终失败摘要。聊天提示又根据摘要中的 timeout 归为“本轮超时，未发布回复”。这句话符合终态，但缺少上游错误和已保存产物的信息。
