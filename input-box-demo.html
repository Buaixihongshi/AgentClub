⌨️ 键盘手感契约 (张楚岚/王也共识)

1. Enter 语义严格解耦：

• 浮层开启时：Enter 与 Tab 仅用于补全当前候选项，绝不发送消息。
• 浮层关闭时：Enter 触发消息发送。
• 中文输入法 IME 组词期间：拦截回车，不影响输入法。

2. 触发与防误触边界：

• @：任意位置输入均可唤起成员名单，支持拼音全拼与首字母（如 @zcl）。
• /：仅允许在文本开头或紧跟已确认成员之后触发，避免输入 URL 或文件路径时误弹。

🎨 候选视觉层级

• @ 成员：强调身份（色彩头像 + 专长微标 + 拼音高亮）

• / 技能：强调 CLI 效率（Monospace 等宽字 + 极简用途释义 + 快捷键标）
